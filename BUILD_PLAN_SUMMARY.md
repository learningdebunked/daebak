### 4. Learn Ratios Page (learn-ratios.html)
**Content - Teaching from First Principles:**

**Section 1: What IS a Ratio?**
- Start concrete: 8 strawberries, 12 raspberries
- "For every 8 strawberries, we need 12 raspberries"
- Visual counting demonstration
- Introduce notation: 8:12, 8 to 12, 8/12

**Section 2: Understanding Relationships**
- Interactive: Change number of bowls, see ingredients update
- "The RELATIONSHIP stays the same"
- Visual table showing pattern
- Not just numbers - a recipe!

**Section 3: Simplifying Ratios**
- Find common factors visually
- 8:12 → 4:6 → 2:3
- "Same relationship, smaller numbers"
- Like reducing fractions

**Section 4: Equivalent Ratios**
- Double the recipe → double EVERYTHING
- Interactive ratio table
- Pattern recognition
- Multiplication preserves relationship

**Section 5: Solving Problems**
- Find per-unit first
- Then scale up or down
- Always check: does it make sense?

**Estimated Time:** 3-4 hours
**Risk:** Medium (new content, must be pedagogically perfect)
