# Learn Ratios Page - Pedagogical Design

## Core Principle
**Ratios are NOT just "two numbers with a colon"**
**Ratios ARE relationships that stay constant when you scale**

## Teaching Sequence (Concrete → Visual → Abstract)

### Section 1: What IS a Ratio? (Concrete)
**Start with fruit bowls:**
- Show 8 strawberries 🍓🍓🍓🍓🍓🍓🍓🍓
- Show 12 raspberries 🫐🫐🫐🫐🫐🫐🫐🫐🫐🫐🫐🫐
- "For every 8 strawberries, we use 12 raspberries"
- This is a RELATIONSHIP, not just numbers

**Key Understanding:**
- Ratio compares quantities
- Order matters! (8:12 ≠ 12:8)
- Three ways to write: 8:12, 8 to 12, 8/12

### Section 2: Ratios Stay Constant (Visual Pattern)
**Interactive table:**
```
Bowls | Strawberries | Raspberries | Ratio
  1   |      4       |      6      |  4:6
  2   |      8       |     12      |  8:12
  3   |     12       |     18      | 12:18
  4   |     16       |     24      | 16:24
```

**Key Understanding:**
- When we double bowls, we double BOTH ingredients
- The relationship stays the same
- 4:6 = 8:12 = 12:18 (equivalent ratios)

### Section 3: Simplifying Ratios (Finding the Pattern)
**Why simplify?**
- Easier to see the relationship
- Smaller numbers, same meaning
- Like reducing fractions

**Visual demonstration:**
```
8:12
  ↓ (divide both by 2)
4:6
  ↓ (divide both by 2)
2:3  ← Simplest form!
```

**Key Understanding:**
- Find common factor
- Divide BOTH sides
- Can't simplify further when no common factors
- 2:3 means "for every 2 strawberries, 3 raspberries"

### Section 4: Scaling Up and Down (The Power of Ratios)
**Given:** 2:3 ratio (simplest form)

**Scale UP (multiply):**
- Need 4 bowls? 2×2 : 3×2 = 4:6
- Need 10 bowls? 2×5 : 3×5 = 10:15

**Scale DOWN (divide):**
- Have 10 strawberries? 10÷2 = 5, so need 3×5 = 15 raspberries

**Key Understanding:**
- Multiply/divide BOTH sides by same number
- Relationship stays constant
- This is how recipes scale!

### Section 5: Common Misconceptions (CRITICAL)
**❌ WRONG: "I can add the same number to both sides"**
- 2:3 → 2+5:3+5 = 7:8 ✗ WRONG!
- This CHANGES the relationship

**✅ RIGHT: "I must multiply/divide both sides"**
- 2:3 → 2×5:3×5 = 10:15 ✓ CORRECT!
- This PRESERVES the relationship

**Visual proof:**
- Show why adding breaks the ratio
- Show why multiplying preserves it

## Interactive Elements

1. **Ratio Builder**
   - Drag strawberries and raspberries
   - See ratio update
   - Try different combinations

2. **Equivalent Ratio Table**
   - Click to add rows
   - See pattern emerge
   - Understand scaling

3. **Simplify Practice**
   - Given ratio (like 8:12)
   - Find common factors
   - Simplify step by step

4. **Scale Calculator**
   - Input: original ratio and scale factor
   - Output: scaled ratio
   - Visual feedback

## Validation Checklist

Before building, ensure:
- [ ] Starts concrete (real strawberries/raspberries)
- [ ] Builds to visual (tables, patterns)
- [ ] Then abstract (notation, operations)
- [ ] Explains WHY, not just WHAT
- [ ] Addresses common misconceptions
- [ ] Interactive elements reinforce understanding
- [ ] No jargon without explanation
- [ ] Connects to prior knowledge (fractions)
- [ ] Real-world context throughout
- [ ] Metacognitive prompts ("Does this make sense?")

## Success Criteria

Student should be able to:
- [ ] Explain what a ratio means in words
- [ ] Write ratios three ways
- [ ] Identify equivalent ratios
- [ ] Simplify ratios to simplest form
- [ ] Scale ratios up and down
- [ ] Explain WHY we multiply (not add) both sides
- [ ] Apply to real-world situations
